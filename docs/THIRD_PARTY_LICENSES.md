# Vendored Rust dependencies

FaultLoom retains each upstream license text inside the checksum-bound
`vendor/<crate-version>/` directory. This inventory reflects `Cargo.lock` and the
normalized SPDX expressions recorded in the build context and CycloneDX SBOM.
The legacy upstream spelling `MIT/Apache-2.0` is normalized to
`MIT OR Apache-2.0`.
